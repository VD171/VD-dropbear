VD Dropbear

A standalone, fully configurable rooted SSH server for KernelSU / Magisk.

⚠ Every connection that authenticates receives a ROOT shell. Treat it like the keys to your device: prefer public keys over passwords, and keep the port off the public Internet.

Android's built-in way to get a shell on your own phone is ADB (USB debugging), and turning it on is invasive and self-exposing. adb_enabled and development_settings_enabled are world-readable settings - any app, SDK or anti-fraud/RASP library can read them, the connection is logged, and there is no supported way to hide that ADB is, or ever was, enabled. The exposure follows you even on a stock, non-rooted phone: to get a shell, you have to announce it.

VD Dropbear is the private alternative. On a rooted device it gives you a real SSH server - root shell, SFTP and rsync over the network - with no adb_enabled tell, no USB-debugging flag, a version banner that reveals nothing, and credentials you control. Your access stays yours, instead of a globally-readable "I am being debugged" flag that anything on the device can read.

Features

  • One daemon, always - start / restart at boot or from the manager's Action button; never more than one instance.
  • Everything is configurable from the WebUI: port; bind to loopback / all / IPv4 / IPv6 / specific addresses; public-key and/or password auth; max auth tries; login user, shell, HOME, extra environment; idle timeout, keepalive; local / remote port forwarding and gateway ports (all off by default); host-key type (ed25519 / rsa / ecdsa).
  • Hidden version banner - the SSH protocol requires a banner, so it cannot be removed, but VD Dropbear replaces it with an uninformative one, so scanners cannot fingerprint the exact server or version and aim known-version attacks at it.
  • Bring your own credentials - add sets of user + key and user + password; the WebUI enforces a minimum password strength and never stores a password in clear text.
  • Every device and emulator - arm64-v8a, armeabi-v7a, x86 and x86_64.

What's included

The SSH server (Dropbear), plus sftp-server, scp and rsync, so you can transfer and synchronise files over the same connection (SFTP, sshfs, GUI clients, backups).

Security model

  • Where secrets live. By default the host key, authorized_keys and password hashes live on credential-encrypted storage, which Android keeps encrypted until you unlock the device. An optional "start before first unlock" mode lets you SSH in before unlock (for example, to unlock the device remotely); its secrets then live on device-encrypted storage, readable pre-unlock - a documented trade-off you opt into only if you need it.
  • Passwords off by default - because every login is root, keys are far safer.
  • No telemetry, no network calls of its own, no analytics. It runs entirely on your device, and it is open source (Apache-2.0) - built from upstream Dropbear with a small, auditable patch set.

Install & configure

Flash the module in the KernelSU or Magisk manager, open its WebUI to set the port and add your keys, then reboot (or press Action to start it now).
