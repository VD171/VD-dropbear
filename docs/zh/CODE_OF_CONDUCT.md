# 行为准则

## 我们的承诺

我们希望参与本项目对每个人来说都是一段没有骚扰的体验，无论年龄、体型、残障、族裔、性征、性别认同与表达、经验
水平、教育程度、社会经济地位、国籍、个人外貌、种族、宗教，还是性身份与性取向。

## 我们的标准

有助于项目的行为：

- 尊重他人、态度友善；
- 优雅地接受建设性反馈；
- 以社区和用户的最大利益为重；
- 对他人展现同理心。

不可接受的行为：

- 骚扰、侮辱或贬损性评论，无论公开还是私下；
- 性化的言语或图像，或不受欢迎的性关注；
- 未经许可公开他人的私人信息；
- 持续扰乱讨论、issue 或 pull request。

## 适用范围

本行为准则适用于所有项目空间 - 仓库、issue、pull request，以及 README 中列出的任何官方渠道 - 以及当有人在公开
场合代表本项目时。

## 执行

请将不可接受的行为报告至 **vd.priv8@pm.me**。报告会以谨慎的方式处理。维护者可以移除、编辑或拒绝违反本行为准则
的贡献和评论，并可对其认为不当、具威胁性或有害的行为封禁贡献者。
