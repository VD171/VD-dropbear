# Kodeks postępowania

## Nasze zobowiązanie

Chcemy, aby udział w tym projekcie był dla wszystkich doświadczeniem wolnym od nękania, niezależnie od
wieku, budowy ciała, niepełnosprawności, pochodzenia etnicznego, cech płciowych, tożsamości i ekspresji
płciowej, poziomu doświadczenia, wykształcenia, statusu społeczno-ekonomicznego, narodowości, wyglądu
osobistego, rasy, religii czy tożsamości i orientacji seksualnej.

## Nasze standardy

Rzeczy, które pomagają projektowi:

- okazywanie szacunku i życzliwości;
- przyjmowanie konstruktywnej krytyki z godnością;
- skupianie się na tym, co najlepsze dla społeczności i użytkowników;
- okazywanie empatii wobec innych.

Rzeczy, które są nie do przyjęcia:

- nękanie, zniewagi lub poniżające komentarze, publiczne lub prywatne;
- język lub obrazy o charakterze seksualnym bądź niepożądane zainteresowanie seksualne;
- publikowanie prywatnych informacji innych osób bez zgody;
- uporczywe zakłócanie dyskusji, zgłoszeń lub pull requestów.

## Zakres

Ten Kodeks postępowania obowiązuje we wszystkich przestrzeniach projektu - w repozytorium, zgłoszeniach,
pull requestach oraz na każdym oficjalnym kanale wymienionym w README - a także wtedy, gdy ktoś
reprezentuje projekt publicznie.

## Egzekwowanie

Zgłaszaj niedopuszczalne zachowania na adres **vd.priv8@pm.me**. Zgłoszenia są rozpatrywane dyskretnie.
Opiekunowie mogą usuwać, edytować lub odrzucać wkład i komentarze naruszające ten Kodeks postępowania,
a także mogą zbanować osoby, których zachowanie uznają za niewłaściwe, groźne lub szkodliwe.
