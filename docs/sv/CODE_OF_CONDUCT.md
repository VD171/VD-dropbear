# Uppförandekod

## Vårt löfte

Vi vill att deltagandet i det här projektet ska vara en upplevelse fri från trakasserier för alla,
oavsett ålder, kropp, funktionsnedsättning, etnicitet, könskaraktäristika, könsidentitet och
könsuttryck, erfarenhetsnivå, utbildning, socioekonomisk status, nationalitet, personligt utseende,
ras, religion eller sexuell identitet och läggning.

## Våra standarder

Saker som hjälper projektet:

- att vara respektfull och välkomnande;
- att ta emot konstruktiv återkoppling med gott omdöme;
- att fokusera på vad som är bäst för gemenskapen och användarna;
- att visa empati mot andra.

Saker som inte är acceptabla:

- trakasserier, förolämpningar eller nedsättande kommentarer, offentligt eller privat;
- sexualiserat språk eller bildspråk, eller oönskad sexuell uppmärksamhet;
- att publicera andras privata information utan tillåtelse;
- ihållande störning av diskussioner, ärenden eller pull-förfrågningar.

## Omfattning

Den här uppförandekoden gäller i alla projektets utrymmen - förvaret, ärenden, pull-förfrågningar och
varje officiell kanal som listas i README - och när någon representerar projektet offentligt.

## Efterlevnad

Rapportera oacceptabelt beteende till **vd.priv8@pm.me**. Rapporter hanteras diskret. Underhållare får
ta bort, redigera eller avvisa bidrag och kommentarer som bryter mot den här uppförandekoden, och får
stänga av bidragsgivare för beteende de anser olämpligt, hotfullt eller skadligt.
