# 행동 강령

## 우리의 서약

우리는 나이, 체형, 장애, 민족, 성적 특징, 성 정체성과 표현, 경험 수준, 교육, 사회경제적 지위, 국적, 외모, 인종, 종교, 또는 성적 지향과 정체성에 관계없이, 이 프로젝트의 참여가 모든 사람에게 괴롭힘 없는 경험이 되기를 바랍니다.

## 우리의 기준

프로젝트에 도움이 되는 것:

- 존중하고 환영하는 태도;
- 건설적인 피드백을 기꺼이 받아들이기;
- 커뮤니티와 사용자에게 가장 좋은 것에 집중하기;
- 타인에 대한 공감 보이기.

받아들일 수 없는 것:

- 공개적이든 사적이든, 괴롭힘, 모욕, 또는 비하 발언;
- 성적인 언어나 이미지, 또는 원치 않는 성적 관심;
- 허락 없이 타인의 사적 정보를 공개하기;
- 토론, issue, 풀 리퀘스트의 지속적인 방해.

## 적용 범위

이 행동 강령은 모든 프로젝트 공간 - 저장소, issue, 풀 리퀘스트, 그리고 README에 나열된 모든 공식 채널 - 에 적용되며, 누군가가 공개적으로 프로젝트를 대표할 때에도 적용됩니다.
