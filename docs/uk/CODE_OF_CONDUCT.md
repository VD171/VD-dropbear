# Кодекс поведінки

## Наша обіцянка

Ми хочемо, щоб участь у цьому проєкті була вільною від домагань для кожного, незалежно від віку,
статури, інвалідності, етнічної приналежності, статевих ознак, гендерної ідентичності та її вираження,
рівня досвіду, освіти, соціально-економічного статусу, національності, зовнішнього вигляду, раси,
релігії чи сексуальної ідентичності та орієнтації.

## Наші стандарти

Те, що допомагає проєкту:

- повага й гостинність;
- гідне сприйняття конструктивного зворотного зв'язку;
- зосередженість на тому, що найкраще для спільноти й користувачів;
- вияв емпатії до інших.

Те, що є неприйнятним:

- домагання, образи чи принизливі коментарі, публічні або приватні;
- сексуалізовані висловлювання чи образи або небажана сексуальна увага;
- оприлюднення приватної інформації інших без дозволу;
- систематичне зривання обговорень, issues чи pull requests.

## Сфера дії

Цей Кодекс поведінки діє в усіх просторах проєкту - у репозиторії, issues, pull requests та будь-якому
офіційному каналі, переліченому в README - а також тоді, коли хтось представляє проєкт публічно.

## Забезпечення дотримання

Повідомляйте про неприйнятну поведінку на **vd.priv8@pm.me**. Звернення розглядаються конфіденційно.
Супровідники можуть вилучати, редагувати чи відхиляти внески й коментарі, що порушують цей Кодекс
поведінки, та можуть блокувати учасників за поведінку, яку вони вважають недоречною, загрозливою чи
шкідливою.
