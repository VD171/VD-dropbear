# مدونة قواعد السلوك

## تعهّدنا

نريد أن تكون المشاركة في هذا المشروع تجربة خالية من المضايقات للجميع، بغض النظر عن العمر أو الجسد أو
الإعاقة أو الأصل العِرقي أو الخصائص الجنسية أو الهوية والتعبير الجندريين أو مستوى الخبرة أو التعليم أو
الوضع الاجتماعي والاقتصادي أو الجنسية أو المظهر الشخصي أو العنصر أو الدين أو الهوية والميول الجنسية.

## معاييرنا

أمور تفيد المشروع:

- التحلّي بالاحترام والترحيب؛
- تقبّل الملاحظات البنّاءة بصدر رحب؛
- التركيز على ما هو أفضل للمجتمع وللمستخدمين؛
- إظهار التعاطف مع الآخرين.

أمور غير مقبولة:

- المضايقة أو الإهانات أو التعليقات المُحقِّرة، علناً أو سراً؛
- اللغة أو الصور ذات الطابع الجنسي، أو الاهتمام الجنسي غير المرغوب فيه؛
- نشر معلومات الآخرين الخاصة دون إذن؛
- التعطيل المتواصل للنقاشات أو المشكلات (issues) أو طلبات الدمج (pull requests).

## النطاق

تنطبق مدونة قواعد السلوك هذه في جميع مساحات المشروع - المستودع والمشكلات وطلبات الدمج وأي قناة رسمية
مذكورة في README - وعندما يمثّل أحدهم المشروع علناً.

## التطبيق

أبلِغ عن السلوك غير المقبول إلى **vd.priv8@pm.me**. تُعالَج البلاغات بسرّية. يجوز للقائمين على الصيانة
إزالة أو تعديل أو رفض المساهمات والتعليقات التي تنتهك مدونة قواعد السلوك هذه، ويجوز لهم حظر المساهمين
على سلوك يرونه غير لائق أو مهدِّداً أو ضاراً.
