# आचार संहिता

## हमारा संकल्प

हम चाहते हैं कि इस परियोजना में भागीदारी सबके लिए उत्पीड़न-मुक्त अनुभव हो, चाहे उम्र, शरीर, दिव्यांगता,
जातीयता, लैंगिक विशेषताएँ, लिंग पहचान और अभिव्यक्ति, अनुभव का स्तर, शिक्षा, सामाजिक-आर्थिक स्थिति,
राष्ट्रीयता, व्यक्तिगत रूप-रंग, नस्ल, धर्म, या यौन पहचान और रुझान कुछ भी हो।

## हमारे मानक

वे बातें जो परियोजना में सहायक हैं:

- सम्मानजनक और स्वागतशील होना;
- रचनात्मक प्रतिक्रिया को सहजता से स्वीकार करना;
- समुदाय और उपयोगकर्ताओं के लिए जो सर्वोत्तम है उस पर ध्यान देना;
- दूसरों के प्रति सहानुभूति दिखाना।

वे बातें जो स्वीकार्य नहीं हैं:

- उत्पीड़न, अपमान, या अपमानजनक टिप्पणियाँ, चाहे सार्वजनिक हों या निजी;
- यौनिक भाषा या चित्रण, या अवांछित यौन ध्यान;
- बिना अनुमति दूसरों की निजी जानकारी प्रकाशित करना;
- चर्चाओं, issues, या pull requests में लगातार बाधा डालना।

यह आचार संहिता सभी परियोजना स्थानों पर लागू होती है - रिपॉज़िटरी, issues, pull requests, और README में
सूचीबद्ध कोई भी आधिकारिक चैनल - और तब भी जब कोई सार्वजनिक रूप से परियोजना का प्रतिनिधित्व कर रहा हो।
