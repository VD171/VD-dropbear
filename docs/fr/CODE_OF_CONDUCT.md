# Code de conduite

## Notre engagement

Nous voulons que la participation à ce projet soit une expérience exempte de harcèlement pour tout le
monde, sans distinction d'âge, de corpulence, de handicap, d'origine ethnique, de caractéristiques
sexuelles, d'identité et d'expression de genre, de niveau d'expérience, d'éducation, de statut
socio-économique, de nationalité, d'apparence personnelle, de race, de religion ou d'identité et
d'orientation sexuelles.

## Nos standards

Ce qui aide le projet :

- se montrer respectueux et accueillant ;
- accepter les retours constructifs avec élégance ;
- se concentrer sur ce qui est le mieux pour la communauté et les utilisateurs ;
- faire preuve d'empathie envers les autres.

Ce qui n'est pas acceptable :

- le harcèlement, les insultes ou les commentaires désobligeants, publics ou privés ;
- un langage ou des images à caractère sexuel, ou une attention sexuelle non souhaitée ;
- la publication d'informations privées d'autrui sans autorisation ;
- la perturbation durable des discussions, des tickets ou des pull requests.

## Portée

Ce Code de conduite s'applique dans tous les espaces du projet - le dépôt, les tickets, les pull requests
et tout canal officiel listé dans le README - ainsi que lorsqu'une personne représente le projet en
public.

## Application

Signalez les comportements inacceptables à **vd.priv8@pm.me**. Les signalements sont traités avec
discrétion. Les mainteneurs peuvent retirer, modifier ou rejeter les contributions et commentaires qui
enfreignent ce Code de conduite, et peuvent bannir les contributeurs dont le comportement leur paraît
inapproprié, menaçant ou nuisible.
