# Código de conducta

## Nuestro compromiso

Queremos que la participación en este proyecto sea una experiencia libre de acoso para todo el mundo,
con independencia de la edad, el cuerpo, la discapacidad, la etnia, las características sexuales, la
identidad y expresión de género, el nivel de experiencia, la educación, la situación socioeconómica, la
nacionalidad, la apariencia personal, la raza, la religión o la identidad y orientación sexual.

## Nuestros estándares

Cosas que ayudan al proyecto:

- ser respetuoso y acogedor;
- aceptar con elegancia las críticas constructivas;
- centrarse en lo que es mejor para la comunidad y para los usuarios;
- mostrar empatía hacia los demás.

Cosas que no son aceptables:

- el acoso, los insultos o los comentarios despectivos, públicos o privados;
- el lenguaje o las imágenes sexualizadas, o la atención sexual no deseada;
- publicar información privada de otras personas sin permiso;
- la interrupción sostenida de debates, incidencias o pull requests.

## Alcance

Este Código de conducta se aplica en todos los espacios del proyecto (el repositorio, las incidencias,
las pull requests y cualquier canal oficial listado en el README) y cuando alguien representa al
proyecto en público.

## Aplicación

Informa de comportamientos inaceptables a **vd.priv8@pm.me**. Los informes se tratan con discreción.
Los mantenedores pueden eliminar, editar o rechazar contribuciones y comentarios que infrinjan este
Código de conducta, y pueden vetar a quienes colaboren con un comportamiento que consideren
inapropiado, amenazante o dañino.
