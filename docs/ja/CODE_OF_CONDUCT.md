# 行動規範

## 私たちの誓い

私たちは、年齢、体格、障害、民族、性的特徴、ジェンダー・アイデンティティと表現、経験の度合い、教育、社会経済的地位、国籍、容姿、人種、宗教、性的指向やアイデンティティにかかわらず、このプロジェクトへの参加がすべての人にとってハラスメントのない体験であることを望みます。

## 私たちの基準

プロジェクトに役立つこと：

- 敬意を持ち、歓迎的であること；
- 建設的なフィードバックを快く受け入れること；
- コミュニティとユーザーにとって最善なことに集中すること；
- 他者への共感を示すこと。

受け入れられないこと：

- 公的・私的を問わない、ハラスメント、侮辱、または侮蔑的な発言；
- 性的な言葉や表現、または望まれない性的な関心；
- 許可なく他者の私的な情報を公開すること；
- 議論、issue、プルリクエストの継続的な妨害。

## 適用範囲

この行動規範は、すべてのプロジェクト空間 - リポジトリ、issue、プルリクエスト、およびREADMEに記載された公式チャネル - に適用され、誰かが公の場でプロジェクトを代表しているときにも適用されます。

## 施行

受け入れがたい振る舞いは **vd.priv8@pm.me** に報告してください。報告は慎重に扱われます。メンテナは、この行動規範に違反する貢献やコメントを削除、編集、または却下することができ、不適切、脅迫的、または有害だと判断した振る舞いについては貢献者を追放することがあります。
