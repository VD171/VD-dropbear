# จรรยาบรรณ

## คำมั่นสัญญาของเรา

เราต้องการให้การมีส่วนร่วมในโครงการนี้เป็นประสบการณ์ที่ปราศจากการคุกคามสำหรับทุกคน โดยไม่คำนึงถึง
อายุ รูปร่าง ความพิการ ชาติพันธุ์ ลักษณะทางเพศ อัตลักษณ์และการแสดงออกทางเพศ ระดับประสบการณ์
การศึกษา สถานะทางเศรษฐกิจและสังคม สัญชาติ รูปลักษณ์ส่วนบุคคล เชื้อชาติ ศาสนา
หรืออัตลักษณ์และรสนิยมทางเพศ

## มาตรฐานของเรา

สิ่งที่ช่วยโครงการ:

- การให้ความเคารพและต้อนรับ;
- การยอมรับคำติชมที่สร้างสรรค์อย่างมีน้ำใจ;
- การมุ่งเน้นไปที่สิ่งที่ดีที่สุดสำหรับชุมชนและผู้ใช้;
- การแสดงความเห็นอกเห็นใจต่อผู้อื่น

สิ่งที่ยอมรับไม่ได้:

- การคุกคาม การดูหมิ่น หรือความคิดเห็นที่ดูถูก ไม่ว่าจะในที่สาธารณะหรือส่วนตัว;
- ภาษาหรือภาพที่มีลักษณะทางเพศ หรือความสนใจทางเพศที่ไม่พึงประสงค์;
- การเผยแพร่ข้อมูลส่วนตัวของผู้อื่นโดยไม่ได้รับอนุญาต;
- การขัดขวางการสนทนา ประเด็นปัญหา หรือ pull request อย่างต่อเนื่อง

## ขอบเขต

จรรยาบรรณนี้มีผลในทุกพื้นที่ของโครงการ - ที่เก็บโค้ด ประเด็นปัญหา pull request และช่องทางอย่างเป็นทางการใด ๆ
ที่ระบุไว้ใน README - และเมื่อมีคนกำลังเป็นตัวแทนของโครงการในที่สาธารณะ

## การบังคับใช้

รายงานพฤติกรรมที่ยอมรับไม่ได้ไปที่ **vd.priv8@pm.me** รายงานจะได้รับการจัดการอย่างรอบคอบ
ผู้ดูแลอาจลบ แก้ไข หรือปฏิเสธการมีส่วนร่วมและความคิดเห็นที่ละเมิดจรรยาบรรณนี้
และอาจแบนผู้มีส่วนร่วมสำหรับพฤติกรรมที่พวกเขาเห็นว่าไม่เหมาะสม เป็นภัยคุกคาม หรือเป็นอันตราย
